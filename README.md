# CC-Portfolio

A portfolio website for a makeup artist and beauty content creator, built with:

- **React 19** — component-based UI
- **Vite** — lightning-fast dev server and build tool
- **Tailwind CSS v3** — utility-first styling
- **shadcn/ui** components (Button, Card, Badge, Input, Textarea, Label, Separator, Dialog)
- **Lucide React** — icon library

## Sections

- **Hero** — full-screen background with CTA buttons
- **Stats** — animated counter strip
- **About** — bio, photo, highlights
- **Services** — 6 service cards (bridal, editorial, occasions, masterclasses, brand, SFX)
- **Portfolio** — filterable gallery with lightbox viewer
- **Testimonials** — carousel with dot navigation
- **Social Feed** — Instagram grid teaser
- **Contact** — validated enquiry form
- **Footer** — links and social icons

## Getting Started

\`\`\`bash
npm install
npm run dev
\`\`\`

Then open [http://localhost:5173](http://localhost:5173).

## Build

\`\`\`bash
npm run build
